# MirrorMate

Prototype of the MirrorMate smart bathroom mirror, built to run in a phone or tablet browser.

- Tap your name (or turn on face recognition in Settings → Mirror) to start a 2-minute brushing session.
- Adults: stories, fun facts, phrase lessons, or a live AI briefing (with a Claude API key).
- Kids: a germ-busting brushing game; with the camera on, brush strokes are tracked by hand movement.
- After brushing, MirrorMate offers one more minute for flossing.

Everything is stored in the browser on the device. Camera images never leave the device.
